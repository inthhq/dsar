## Meaning

The SDK received an HTTP response that could not be parsed as a valid error envelope.

## Probable Causes

- Server returned non-JSON or malformed JSON.
- Response missing required envelope fields.
- Proxy or middleware altered the response.

## How to Fix

1. Verify server returns valid JSON error envelope.
2. Check for proxies that modify responses.
3. Ensure SDK and server versions are compatible.

## Retryable

No. Retry only after fixing response format.

## Minimal Trigger Example

```ts
// Server returns HTML error page instead of JSON
await client.requests.capture({ ... });
```
