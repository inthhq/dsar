## GET /subjects/:subjectId

Look up a subject profile by matching requests.

Indexed `listBySubject` p95 at 1,000 in-memory SQLite rows is gated by
`bun run bench`. See [Performance Benches](../testing/perf-benches.md).

The endpoint searches all requests for matching subject identifiers across:

- `capture.subject.subjectId`
- `capture.subject.externalRef`
- `requestor.email`

**Response (200):**

```json
{
	"subjectId": "sub-123",
	"requests": [
		{
			"id": "req-456",
			"status": "in_progress",
			"receivedAt": "2026-01-15T00:00:00.000Z"
		}
	]
}
```
