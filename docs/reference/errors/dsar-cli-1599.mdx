## Meaning

The runtime emitted an error code that is not present in the CLI catalog and fell back to uncataloged handling.

## Probable Causes

- New error code emitted without catalog/docs entry.
- Typo in reason code string from throw site.

## How to Fix

1. Add the missing code to CLI catalog.
2. Add matching per-code docs markdown file.
3. Update tests.

## Retryable

Yes for transient failures, but treat as a release-quality defect.

## Minimal Trigger Example

A mapper returns a code not defined in the CLI error catalog.
