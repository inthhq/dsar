## Meaning

No active policy activation was found for the tenant/workspace scope.

## Probable Causes

- Policy upgrade has not been activated for the target scope.
- Request references a workspace without a policy activation.

## How to Fix

1. Activate a policy pack for the target tenant/workspace.
2. Re-run the request with a scope that has an active policy.

## Retryable

No. Retry only after policy activation exists.

## Minimal Trigger Example

```http
GET /api/v1/policies/active?tenantId=tenant-default HTTP/1.1
Host: localhost:4086
authorization: Bearer test-token
```
