## Meaning

An unhandled persistence layer runtime exception occurred.

## Probable Causes

- Unexpected bug in persistence logic.
- Backend storage failure not mapped to a typed domain error.

## How to Fix

1. Inspect logs for stack trace and context.
2. Add explicit domain error mapping for the failing boundary.
3. Patch root cause and add regression tests.

## Retryable

Yes, but only when failure is transient. Persistent failures require code fix.

## Minimal Trigger Example

Any uncaught exception thrown during persistence operations.
