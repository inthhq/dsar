DSAR ships generated OpenAPI at `GET /spec.json` and interactive HTTP docs at
`GET /docs`, but the markdown docs in this folder explain how the runtime,
integrations, and request lifecycle fit together.

## Start Here

1. [Getting Started](./getting-started.md) for the fastest local path using the
   example apps and runtime.
2. [Request Lifecycle](./request-lifecycle.md) for the end-to-end operator and
   subject workflow.
3. [SDK and Runtime Modes](./developer/sdk-and-runtime.md) to choose between
   `@dsar/backend`, `@dsar/node-sdk`, `@dsar/cli`, and `@dsar/core`.
